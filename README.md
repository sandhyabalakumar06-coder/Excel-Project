# 📊 Sales Data Analysis Dashboard | Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing sales data using Microsoft Excel to understand sales performance across different products and regions. An interactive dashboard was developed to track key sales metrics and identify top-performing products and regions.

## 🎯 Objectives

- Analyze product-wise and region-wise sales performance.
- Calculate key sales metrics using Excel formulas.
- Create interactive visualizations for better data understanding.
- Identify top-performing products and regions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Excel Formulas: `SUM`, `COUNTA`, `SUMIF`
- PivotTables
- PivotCharts
- Slicers
- Data Visualization

## 📈 Key Features

- **Sales Overview:** Displays total sales, total orders, and total quantity.
- **Product-wise Analysis:** Analyzes revenue generated by different products.
- **Region-wise Analysis:** Compares sales performance across regions.
- **Interactive Dashboard:** Uses PivotCharts and slicers to explore sales data dynamically.
- **Dynamic Filtering:** Region slicer allows users to filter dashboard results interactively.

## 🔍 Key Learnings

- Data cleaning and organizing in Excel.
- Using formulas to calculate sales metrics.
- Creating PivotTables and PivotCharts.
- Connecting slicers to dashboard charts.
- Presenting business insights through data visualization.

## 📂 Project Files

- `Sales_Data_Analysis_Dashboard.xlsx` – Excel workbook containing the sales analysis, PivotTables, charts, slicers, and dashboard.

## 🚀 How to Use

1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Use the Region slicer to filter and explore sales performance.
5. Review the charts and key sales metrics.
